Vireo Bay is a 2D top-down open-world crime game set in a golden-hour coastal city. Dana Voss owes the Bay Syndicate $5,000. Steal cars, lose the cops, run four jobs across the beach, the downtown towers, the port and the suburbs — and pay the debt. Drive and walk with WASD, enter or steal a car with E, punch with Space, shoot with F, pause with P. Plain JavaScript and canvas, no network, no assets, fully offline.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a browser.
